# Cálculo Grátis 2026 📊

O maior portal brasileiro de calculadoras e simuladores online, gratuito e focado em alta performance.

## 🚀 Visão Geral

O **Cálculo Grátis** é uma aplicação Next.js (App Router) 100% estática (SSG) que oferece mais de 60 ferramentas de cálculo nas áreas de:
- **Trabalhista**: Rescisão, Salário Líquido, Seguro Desemprego, FGTS, etc.
- **Financeiro**: Juros Compostos, Financiamento (Price/SAC), Amortização.
- **Saúde**: IMC, Peso Ideal, Consumo de Água.
- **Matemática**: Regra de Três, Porcentagem, Calculadora Científica.
- **Utilidades**: Geradores de CPF/CNPJ, Formatadores de JSON, Fuso Horário.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Internacionalização**: PT-BR e ES (Espanhol)
- **Analytics**: Google Analytics 4 (GA4) custom event tracking
- **Deployment**: Vercel (Static Export)
- **Testes**: Vitest

## ✨ Diferenciais

- **100% Client-side**: Os cálculos rodam no navegador do usuário, garantindo privacidade e velocidade instantânea.
- **Modo Offline (PWA)**: Funciona sem internet após o primeiro acesso.
- **Histórico Local**: Salva seus cálculos recentes no LocalStorage (sem necessidade de conta).
- **Widgets Embutíveis**: Permite que outros sites incorporem nossas calculadoras via iframe.
- **SEO Premium**: Metadata dinâmico, Sitemap completo e JSON-LD para rich snippets no Google.

## 💻 Desenvolvimento

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev -p 3020

# Rodar testes
npm test

# Build de produção (Export Estático)
npm run build
```
