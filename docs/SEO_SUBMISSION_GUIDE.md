# SEO Submission Guide - calculo.gratis

Once the site is live on Vercel, follow these steps to ensure rapid indexing.

## 1. Google Search Console (GSC)
1. Add property: `https://calculo.gratis`
2. Go to **Sitemaps**.
3. Submit: `https://calculo.gratis/sitemap.xml`
4. Use the **URL Inspection** tool to request indexing for the home page and top 4 tools:
   - `https://calculo.gratis/trabalhista/rescisao`
   - `https://calculo.gratis/trabalhista/salario-liquido`
   - `https://calculo.gratis/saude/imc`
   - `https://calculo.gratis/financeiro/juros-compostos`

## 2. Bing Webmaster Tools
1. Add property: `https://calculo.gratis` (or import from GSC).
2. Submit sitemap: `https://calculo.gratis/sitemap.xml`

## 3. Spanish Version (LATAM)
Verify that GSC recognizes the `hreflang` tags.
- Primary: `https://calculo.gratis`
- Alternate (ES): `https://calculo.gratis/es`

## 4. Robots.txt
Confirm it is live at `https://calculo.gratis/robots.txt` and points to the sitemap.
