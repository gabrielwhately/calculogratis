# Plantillas de Alcance para Socios (Español) - calculo.gratis

Este documento contiene plantillas para la Fase 2 de la estrategia de crecimiento: "El Sprint del Widget". Nuestro objetivo es ofrecer integraciones (embeds) gratuitas de alta calidad a blogs y portales relevantes a cambio de enlaces (backlinks).

**Mensaje:**
